# 🎮 Rock Paper Scissors

A simple and interactive **Rock Paper Scissors** game built with **HTML, CSS, and JavaScript**. Play against the computer in a best-of-five match (first to 3 wins).

> 🚀 Built while learning JavaScript game development.

## ✨ Features

- 🎮 Play against the computer
- 🤖 Random computer choice generation
- 🏆 First to 3 wins the match
- 📊 Live score tracking
- 🔄 Reset game functionality
- 🎯 Game-over state prevents further moves

## 🚀 Getting Started

1. Clone the repository

```bash
git clone https://github.com/your-username/rock-paper-scissors.git
```

2. Open the project folder.

3. Run `index.html` in your browser.

---

## 🎯 How to Play

1. Choose **Rock**, **Paper**, or **Scissors**.
2. The computer randomly selects its move.
3. Scores update after every round.
4. The first player to reach **3 wins** wins the match.
5. Click **Reset** to start a new game.
